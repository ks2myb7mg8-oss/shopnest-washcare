# ShopNest · Күтім құралдарының көтерме каталогы (қазақша)

Бұл пакет толық ShopNest бастапқы коды емес. Railway Docker құрастыру кезінде `sti-technical/shopnest-ecommerce` репозиторийін GitHub-тан жүктеп алады, содан кейін осы пакеттегі қазақша каталог пен аударма қадамдарын қолданады. Сондықтан платформа GitHub-қа қол жеткізе алуы керек.

## Не бар
- 9 тауар (қазақша атауы мен сипаттамасы), 10 сурет. Жасыл кондиционердің екі суреті бір тауарға тиесілі, каталогта біріншісі көрсетіледі.
- Сайттың барлық мәтіні қазақша: мәзір, түймелер, формалар, себет, тапсырыстар, әкімші тақтасы, қате хабарламалары.
- Баға теңгемен көрсетіледі (мысалы, 2 500 ₸). Бағалар суреттердегі көтерме бағадан алынған.
- Тапсырыс күйлері экранда қазақша көрінеді (Қабылданды, Өңделуде, Жөнелтілді, Жеткізілді, Бас тартылды).
- Телефонға бейімделген CSS.

## Маңызды: суреттердегі жазулар
Тауар суреттеріндегі жазулар (мысалы, «Шампунь без сульфатный», «Оптом 1500 тг») суретке орыс тілінде кірістірілген. Оларды код арқылы өзгерту мүмкін емес. Қазақша жазуы бар суреттер қажет болса, Canva, Photoshop сияқты бағдарламада мәтінді ауыстырып, жаңа суреттерді `photos` папкасына сол файл атымен салыңыз. Сайттың өз мәтіндері мен тауар атаулары толық қазақша.

## Railway арқылы жариялау
1. GitHub-та жеке репозиторий жасаңыз: `shopnest-washcare`.
2. ZIP-ті ашып, ішіндегі **барлық файлды** репозиторийдің түбіне жүктеңіз (`Dockerfile`, `customize.js`, `kazakh.js`, `railway.json`, `photos` папкасы). ZIP-тің өзін жүктемеңіз.
3. Railway → New Project → Deploy from GitHub repo, осы репозиторийді таңдаңыз.
4. Service → Variables бөлімінде үш айнымалы қойыңыз:
   - `ADMIN_PASSWORD`: кемінде 12 таңбалы, бірегей әкімші құпиясөзі (GitHub-қа жүктемеңіз).
   - `JWT_SECRET`: кемінде 32 таңбалы кездейсоқ жол, құпия.
   - `DB_PATH`: `/data/shopnest.db`
5. Қызметке Volume қосып, `/data` жолына тіркеңіз. Нақты тапсырыс қабылдамас бұрын Volume орнатылуы керек. Бір SQLite базасын екі инстанс арасында бөліспеңіз.
6. Құрастыру аяқталған соң Networking → Generate Domain арқылы https://... мекенжайын алыңыз.
7. Телефоннан ашып, «Күтім» санатын, тоғыз тауарды, бағалар мен суреттерді тексеріңіз. Әкімші тақтасы: `https://сіздің-домен/admin.html`, логин `admin@shopnest.com`, құпиясөз — өзіңіз қойған `ADMIN_PASSWORD`.

## Ескертулер
- Түпнұсқа жоба — оқу жобасы. Нақты тұтынушы деректерімен, төлеммен немесе тапсырыспен жұмыс істеместен бұрын аутентификацияны, құпиялылықты, төлем қауіпсіздігін және резервтік көшірмені тексеру керек.
- Бұрыннан іске қосылған база болса, `ADMIN_PASSWORD` өзгерту базадағы әкімші құпиясөзін өзгертпейді.
- Бұрынғы базада ескі (қытайша) тауарлар қалған болса, жаңа каталог көрінуі үшін `/data/shopnest.db` файлын жойып, қайта іске қосыңыз, не әкімші тақтасынан тауарларды өңдеңіз.
- Әкімші тақтасынан жаңа тауар қосқанда сурет тек URL арқылы беріледі, телефоннан тікелей жүктеу жоқ.
- Суреттегі баға мен көлемнің нақты тауармен сәйкестігін жариялар алдында тексеріңіз.
